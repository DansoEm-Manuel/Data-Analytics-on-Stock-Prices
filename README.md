# 🚀 Level 2 – Intermediate Analytics Projects

## Regression Analysis

File: Regression Analysis.ipynb

### Objectives

Predict stock closing prices using machine learning techniques.

### Techniques Used

* Linear Regression
* Feature Selection
* Model Evaluation

### Evaluation Metrics

* Mean Squared Error (MSE)
* R² Score

### Outputs

* Actual vs Predicted Price Comparison
* Regression Performance Visualization

---

## Time Series Analysis

File: Time Series Analysis.ipynb

### Objectives

Analyze stock price behavior over time and identify trends.

### Techniques Used

* Trend Analysis
* Stationarity Testing
* First Differencing
* Moving Average Smoothing
* Seasonal Decomposition

### Insights Generated

* Long-term trends
* Seasonal patterns
* Time-dependent fluctuations

---

## K-Means Clustering

File: K-means Clustering.ipynb

### Objectives

Group stock data into meaningful clusters using unsupervised learning.

### Techniques Used

* StandardScaler
* K-Means Clustering
* Elbow Method

### Outputs

* Cluster Identification
* Cluster Visualization
* Market Segment Analysis
