# Data-Analytics-Internship-Projects
Python-based data analytics internship projects covering data cleaning, EDA, visualization, regression analysis, time series analysis, and K-Means clustering using real-world datasets.

This repository contains analytical tasks completed during a Data Analytics Internship Program using Python and data analytics libraries.

🔧 Tools & Libraries
Python
Pandas
Matplotlib
Seaborn
Scikit-learn
Statsmodels
Jupyter Notebook

 Level 1 – Foundational Data Analytics

 Data Cleaning & Preprocessing
Handled missing values and duplicate records
Standardized datasets for consistency and analysis readiness

Exploratory Data Analysis (EDA)
Performed statistical analysis and feature exploration
Created histograms, boxplots, heatmaps, and scatter plots to identify patterns and relationships

 
Data Visualization
Developed bar charts, line charts, and scatter plots using Matplotlib and Seaborn
Customized visualizations with titles, labels, legends, and formatting for better storytelling
 Level 2 – Intermediate Analytics Projects
 Regression Analysis
Built a Linear Regression model to predict stock closing prices
Evaluated model performance using Mean Squared Error (MSE) and R² Score
Visualized actual vs predicted stock prices
 Time Series Analysis
Analyzed stock price trends over time
Performed stationarity testing and first differencing
Applied moving average smoothing and seasonal decomposition techniques
 K-Means Clustering
Standardized features using StandardScaler
Applied the elbow method to determine the optimal number of clusters
Visualized clusters using scatter plots and evaluated clustering performance
